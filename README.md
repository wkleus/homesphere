# Real Estate Frontend

![React](https://img.shields.io/badge/React-19.0+-61DAFB?logo=react&logoColor=white)
![Status](https://img.shields.io/badge/Status-Work_in_Progress-yellow)

A modular React frontend for displaying and managing residential properties such as houses and apartments.
The project focuses on reusable UI components, clean architecture, and scalable structure.

## Features

- Component-driven architecture
- Property listings (houses & apartments)
- Modular UI elements (details, labels, images etc.)

## Tech Stack

- React
- JavaScript
- CSS Modules / Styled Components

## Project Structure (initial draft)

```
homesphere/
  src/
    components/
      Header/
      Title/
      Main/
        RealEstate.jsx
        RealEstate.css
        RealEstateCard/
      Footer/
    ...
```

## Setup

```
git clone https://github.com/wkleus/homesphere.git
cd homesphere
npm install
npm run dev
```
